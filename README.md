# cowork-algeria

Liste des espaces de coworking à Alger, avec tentative de classement selon
les avis Google positifs.

Voir [`data/coworking-algiers.md`](data/coworking-algiers.md) pour le tableau
et les [données brutes en CSV](data/coworking-algiers.csv).

**Important** : les vraies notes/avis Google Maps n'ont pas pu être
récupérées depuis cet environnement d'exécution (accès réseau à Google
bloqué par la politique du sandbox). Le fichier détaille la méthodologie,
les limites, et comment obtenir un classement fiable via la Google Places
API si une clé API est fournie.
